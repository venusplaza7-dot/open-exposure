# OPEN EXPOSURE - Free Daybreak Alternative

Free, open-source, 100% local security audit OS for any company.

Every company leaks secrets. This tool finds them in 60 seconds.

### Why this is universal?
- Runs 100% in browser - no data leaves your machine
- No API key needed for basic scan
- Works for any GitHub org, any domain

### What it scans now (v1)
- Public GitHub secret leaks
- Exposed env files
- Public config files

### Roadmap
- [ ] Tech stack waste scanner

### Run
npm install
npm run dev
